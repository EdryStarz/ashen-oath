BEFORE YOU ENTER THE FOREST

A few things
worth knowing.

Is it really free?

Yes. This build has no ads, subscriptions or in-app purchases.

Can I play in English?

This website is bilingual. The current Android game interface is Russian. An English game translation is not included in version 0.7.2.

Is this a big, endless RPG?

It is a small first chapter: three creatures, progression, equipment and a habit planner. No multiplayer, cloud sync or reminders yet.

What happens to my progress?

It is saved locally. Export your JSON from the Journal before uninstalling or changing from an old debug build to a release build. Deleting the app without a backup removes local progress.

How do I install it?

Download the APK from our GitHub release, open it on a compatible Android device and allow installation from that source when Android asks. You need Android 7.0+ and a 64-bit ARM or x86 device.

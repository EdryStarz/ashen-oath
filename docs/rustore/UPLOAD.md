# Подготовка публикации в RuStore

Сборка: Пепельный обет 0.7.2 (versionCode 12)
Разработчик для карточки: Embertrail Studio
Контакт поддержки: edrystars@gmail.com

## Загрузка

1. Верифицировать свой аккаунт разработчика в RuStore Консоли. Юридические сведения должны быть фактическими; Embertrail Studio — отображаемый бренд.
2. Разместить privacy-policy.html на доступном по HTTPS сайте. Проверить доступ без авторизации и вставить публичную ссылку в карточку.
3. Добавить приложение «Пепельный обет». Загрузить только ashen-oath-0.7.2-release.apk.
4. Перенести тексты из store-listing.md. Заполнить контакты, выбрать категорию, пройти анкету возраста и декларацию данных. Предлагаемый рейтинг 12+ требует подтверждения анкетой.
5. Загрузить icon-512.png и четыре PNG из screenshots-phone и четыре PNG из screenshots-tablet. Иконка совпадает с оформлением установленного приложения. Скриншоты получены из рабочего приложения на изолированном демонстрационном сохранении; Android-системных панелей на них нет.
6. Проверить предварительный просмотр карточки, данные и работу приложения на целевых телефонах. Отправить на модерацию вручную. Это подготовленный комплект; приложение ещё не загружено и не опубликовано.

Подробные правила: https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication
Подписи: https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/apk-signature

## Сборка и подпись

Повторная сборка: tools/build_rustore_release.ps1. Она использует release-шаблон Godot, выравнивает APK для библиотек с 16-КБ страницами и подписывает сертификатом Embertrail Studio (RSA 3072, APK v2/v3). INTERNET, чувствительные разрешения и флаг debuggable отсутствуют. Android 7.0+; ARM64 и x86_64.

Ключ: %USERPROFILE%/.codex/signing/ashen-oath/ashen-oath-release.jks
Зашифрованные учётные данные: signing-credential.xml рядом с ключом. Эти файлы НЕ входят в архив для магазина, репозиторий или архив исходников.

Сохраните резервную копию JKS и пароль в защищённом месте/менеджере паролей. XML защищён Windows DPAPI: восстановление из него возможно только тем же пользователем Windows, поэтому одной его копии для переноса на другой компьютер недостаточно. Пароль можно посмотреть локально через Import-Clixml и GetNetworkCredential().Password; не отправляйте его в чат, логи или магазин. Не теряйте ключ: все обновления этого пакета должны иметь ту же подпись. Если приложение уже публиковалось с другим ключом, потребуется исходный ключ, а не этот новый.

## Переход с прежней тестовой APK

Ранее использовалась debug-подпись. Android не позволит обновить такую установку новой release-подписью. Перед переходом: Журнал → Экспорт сохранения; сохранить JSON отдельно; удалить тестовое приложение; установить release APK; Журнал → Восстановить из JSON. Удаление приложения без экспорта потеряет локальный прогресс. Установки будущих release-обновлений сохраняют данные при той же подписи и повышенном versionCode.

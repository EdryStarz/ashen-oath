Обе попытки генератора дизайн-системы предложили общий Hero + Features + CTA и Minimalism/Swiss. Соответствие задаче не подтвердилось: результат не сохранён как эталон и не использован для структуры экрана. Приняты релевантные рекомендации поиска: Android48dp, расстояние между действиями, управляемая анимация и serif/sans. Cormorant выбран для заголовков, Noto Sans для интерфейса и широкого покрытия кириллицы. Никакого специального Unity/Godot-модуля скилла не запускалось. Принципы перенесены в Godot Control; Compose отсутствует.

## Художественный ориентир

**The Witcher3: Wild Hunt, PC/PS5/Xbox Series next-gen, ветка4.0–4.04**: холодный сумеречный свет, локальные огни, изношенная сталь, ткань/кожа, наблюдаемая подготовка к охоте. Берём направление материалов и света, не интерфейс, персонажа или степень технической готовности. Официальное описание [next-gen update](https://www.thewitcher.com/us/en/news/46681/the-witcher-3-wild-hunt-next-gen-update-trailer-and-redstreams-summary). Рейтрейсинг и качество AAA не заявлены и для первой мобильной сцены не требуются.

Герой стоит в настоящей интерактивной3D-сцене; фон лагеря не является концепт-артом или видео. Прототипные модели не художественно финальные. Список расположен под сценой, без эффектов поверх текста. Никаких эмодзи, стеклянных карточек, фиолетовых градиентов и декоративной пыли. Однотонные поверхности UI читаемее имитации камня под каждым словом; физические материалы остаются в3D.

Нижняя навигация: лагерь, привычки, герой, охота, журнал. Подписи постоянны, текущее место выделено фоном и цветом. Собственный векторный знак резонатора используется для приложения; иконки без понятной подписи не требуются. Никаких скрытых действий только по свайпу. Поворот героя — дополнительный жест, не путь к важной функции.

## Состояния и доступность

Кнопки имеют normal/pressed/focus/disabled. Ошибки формы остаются рядом с полями; невалидный импорт не меняет состояние. Прогресс сообщается текстом с точным XP. Минимальная версия открывает понятное описание, отдых не наказывает. Перед закрытием результата охоты данные уже записаны.

В настройках текст100/120/140%, уменьшение движения и экономичный режим. Бой можно пропустить; камера не трясётся. AndroidBack закрывает модальное окно или возвращает в лагерь. Формы прокручиваются, нижняя навигация фиксирована. Системная клавиатура и зоны жестов дополнительно проверяются на Android; в этой версии полноэкранный режим и нижний отступ12, без обещания универсальной поддержки всех вырезов.

Для коммерческого релиза остаются: TalkBack на физическом устройстве, автоматическое следование системному размеру шрифта, проверка всех экранов при200%, пересчёт safe-area под вырезы и edge-to-edge, контраст каждого состояния в финальном рендере. Контраст основных пар проверяется скриптом `tools/check_contrast.py`. Автотесты форм не доказывают доступность для всех пользователей.

## Universal Modder

Прочитаны `mod-any-game`, `asset-pipeline` и `game-automation` установленного плагина0.2.0. Используется его подход: исходник → один вертикальный срез → реальный запуск → скриншот и лог → исправление. Выполнен `um kb search Godot` (готовых заметок не найдено), подготовлен `um publish check` для пакета. Источники/команды/реальные результаты записываются в `MODLOG.md` и `docs/TOOLCHAIN.md`.

Скилл не превращает картинку в готовую анимированную модель. `fal` и платные генерации не вызывались. Все программные модели в `world.gd` созданы для этого проекта; не выполнялась распаковка чужих игр. [Universal Modder](https://github.com/rehan-remade/universal-modder).
